# ADR 0006 — 장기 자율 실행의 6장치

- 날짜: 2026-09-06 (21강)
- 상태: 채택

## 맥락

사람이 매 턴을 보지 않는 자율 실행은 세 가지로 무너진다 — 폭주(무한 재시도·루프로 토큰·요금 소모), 표류(흐린 성공 기준으로 엉뚱한 방향), 유실(컨텍스트·세션이 끊겨 처음부터). 20강이 호출 하나의 신뢰성이라면 이 결정은 세션 전체의 안전장치다.

## 결정

여섯 장치를 전부 레포의 파일·설정으로 둔다. 모델의 기억이나 프롬프트에 맡기지 않는다.

| # | 장치 | 실물 |
|---|---|---|
| ① 검증 가능한 성공 기준 | 기계가 판정 | `docs/autonomy/작업로그.md`의 `성공기준` 줄 = `python3 -m pytest -q` 초록 |
| ② 결정적 게이트 + 자기수정 루프 | 초록까지 멈춤 차단 | `.claude/settings.json` Stop → `.claude/hooks/gate-pytest.sh` (exit 2 + stderr 피드백) |
| ③ 격리 | blast radius 제한 | `scripts/autorun.sh` — 컨테이너 안에서만 `--dangerously-skip-permissions`, 밖이면 allowlist |
| ④ 비용·재시도 상한 | 양을 막는다 | `--max-turns 40` · `--max-budget-usd 5` · `MAX_THINKING_TOKENS=8000` · 게이트 연속 차단 상한 `GATE_MAX_BLOCKS=3` |
| ⑤ 진행 로그 + 체크포인트 | 안 휘발하는 곳 | `docs/autonomy/작업로그.md`(서술) + 의미 있는 상태(red·green)의 커밋(스냅샷) |
| ⑥ 관측 + 사람 개입 | 블랙박스 금지 | `CLAUDE_CODE_ENABLE_TELEMETRY=1`(OTel) · `autorun_render.py`가 턴·도구·게이트를 화면에 · 게이트가 상한에 닿으면 로그에 `⛔ HITL` 줄 · 금융 판단이 바뀌는 변경은 자동 통과 없음 |

## 근거

- 게이트 연속 차단 상한: 영영 못 맞추는 테스트에 밤새 도는 실패 루프를 끊는다(20강 서킷 브레이커의 자율 버전). 상한에 닿으면 막지 않고 사람에게 넘긴다 — 게이트는 벽이 아니라 층.
- 격리와 상한은 다른 축: 격리는 범위(파일·시스템), 상한은 양(턴·달러·토큰). 컨테이너 안이라도 상한이 없으면 요금은 밖으로 나간다.
- 로그와 커밋은 역할이 다르다: 로그는 "다음에 뭘 할지", 커밋은 "언제든 돌아갈 스냅샷". 새 세션이 로그만 읽고 이어갈 수 있어야 한다(세션 전사에 의존하지 않는다).
- `/goal`은 쓰지 않는다: 조건 충족 판정을 작은 모델이 대화 내용으로 내린다. 방향 잡기엔 쓸 수 있지만 우리 성공 기준의 판정자는 pytest여야 한다.

## 결과

- `ch3-21-interrupted`: 6장치 세팅 + red 테스트 + 로그 = "밤에 세션이 끊긴 상태"의 재현 스냅샷.
- 재개는 `scripts/autorun.sh` 한 줄. 새 세션이 로그를 읽고 남은 항목을 이어간다.
