# ADR 0003 — 검색 점수를 IDF 가중으로 바꾸고 근거 게이트 임계값을 재캘리브레이션

## 상태
채택 (2026-08)

## 맥락
[ADR 0002](0002-evidence-score-gate.md)는 근거 부실 게이트를 **토큰 겹침 개수 비율** 위에 얹으면서
두 가지 한계를 명시적으로 남겼다.

- 조사가 붙은 토큰(`한도가` vs `한도`)이 안 겹쳐 커버리지가 실제 관련성보다 낮게 나온다.
- 모든 토큰을 같은 무게로 세기 때문에 `"연금"` 한 단어 질문은 커버리지 **1.00**으로 게이트를
  그냥 통과한다 — 짧은 질문일수록 게이트가 무력해지는 구조적 약점.

두 번째가 특히 문제였다. 근거가 사실상 없는 한 단어짜리 질문이 정상 답변(`✅`)으로 나갔고,
이는 게이트를 도입한 목적 자체를 무너뜨린다.

또 `IRP로`처럼 영문+조사가 한 토큰으로 붙으면 `IRP`와 겹치지 않아, 명백히 연금 범위인 질문이
"관련 근거 문서를 찾지 못했다"로 떨어졌다.

## 결정
검색 스코어를 **IDF 가중 + 접사 정규화 + 복합명사 포함 매칭**으로 바꾸고,
그 위에서 임계값을 다시 측정해 잡는다. 임베딩·형태소 분석기는 여전히 쓰지 않는다
(표준 라이브러리 우선 — CLAUDE.md 컨벤션).

1. **접사 정규화** — 조사·어미 목록을 잘라낸 형태를 질문·문서 양쪽에서 후보로 함께 들고 간다.
   `한도가`→`한도`, `irp로`→`irp`, `해지하면`→`해지`. 어간이 2글자 미만으로 줄어드는 절단은
   막는다(`한도`에서 `도`를 떼어 `한`으로 만들지 않는다).
2. **복합명사 포함 매칭** — 질문 쪽 형태가 문서 토큰 **안에** 들어 있으면 근거로 친다
   (`해지` ⊂ `중도해지`). 방향은 질문 → 문서 한쪽만 연다. 반대로 열면 문서의 `연금`이
   질문의 `연금소득세`를 커버한 것으로 쳐서 특이 용어의 IDF가 무너진다.
3. **IDF 가중** — `log(1 + (N − df + 0.5) / (df + 0.5))`. `df`에는 **1의 하한**을 둔다.
   어느 문서에도 없는 토큰이 가장 희귀한 실제 용어보다 무거워지면, 질문에 이메일 한 줄만
   붙어도 커버리지가 무너진다.
4. **커버리지 분모의 하한** — `max(Σ idf(질문 토큰), idf(df=1))`.
   순수 비율이면 질문이 짧을수록 만점에 가까워지는 구멍이 남는다. 하한은
   "가장 희귀한 용어 하나만큼의 정보량"이고, 그만큼도 안 되는 질문은 만점을 받지 못한다.
5. **홀로 선 접사는 내용어가 아니다** — `"문의는 … 으로"`의 `으로`를 질의에서 뺀다.
   빼지 않으면 문서의 `연금으로` 안에 걸려 근거로 잡히고 랭킹까지 뒤집는다.

임계값은 `data/` 3개 문서에 21개 질문을 실측해 다시 잡았다.

```
0.00 ─── 보류 ─── 0.15 ── 저신뢰 ── 0.50 ─── 정상 ─── 1.00
```

`HARD_THRESHOLD`는 0.15 그대로, `SOFT_THRESHOLD`는 **0.40 → 0.50**.
경계는 종전대로 `>=` 통과다.

## 결과

**닫힌 구멍**

- `"연금"` 한 단어: 커버리지 **1.00 → 0.136**. 정상 답변으로 나가던 것이 보류로 바뀌었다.
  ADR 0002가 "필요해지면 추후 ADR"로 미뤄둔 항목을 여기서 닫는다.
- `"퇴직금 받았는데 IRP로 옮기면…"`: `IRP로`가 `IRP`에 걸리면서 빈 결과가 아니라
  **근거 이름을 보여주는 보류**(0.087)가 됐다. 여전히 차단이고 LLM도 부르지 않는다.
- 조사 미스매치가 사라져 `한도가`·`납입액을` 같은 토큰이 실제로 근거에 걸린다.

**구간이 올라간 질문 — 유일하게 느슨해진 방향**

`"연금 해지하면 어떻게 되나요"`는 ADR 0002에서 저신뢰(0.25)였으나 이제 정상(0.532)이다.
`해지하면`이 문서의 `중도해지` 절에 걸렸기 때문이고, 그 절이 실제로 이 질문에 답한다
(기타소득세 16.5%). 예전 저신뢰 판정은 근거가 약해서가 아니라 **검색기가 근거를 못 찾아서**
나온 값이었다. 나머지 어떤 질문도 보류 → 정상으로 올라오지 않는다.

**실측 분포 (21개 질문)**

| 커버리지 | 질문 | 구간 |
|---|---|---|
| 0.000 | 퇴직 위로금 협상 노하우 알려줘 | 검색 결과 없음 |
| 0.043 | 연금 나이 제한 있나요 | 보류 |
| 0.087 | 퇴직금 받았는데 IRP로 옮기면 세금 어떻게 되나요? | 보류 |
| 0.125 | 연금저축 관련해서 요즘 날씨랑 점심 메뉴… | 보류 |
| 0.136 | 연금 | 보류 |
| 0.250 | 연금저축 계좌이체 절차 알려줘 | 저신뢰 |
| 0.281 | 연금저축 세액공제 한도가 얼마인가요 문의는 hong@example.com 으로 | 저신뢰 |
| 0.324 | IRP 중도인출 되나요 / IRP 담보대출 되나요 | 저신뢰 |
| 0.333 | 연금저축 수수료 비교해줘 | 저신뢰 |
| 0.362 | 연금 해지 수수료 얼마인가요 | 저신뢰 |
| 0.425 | IRP 운용 상품 추천해줘 | 저신뢰 |
| 0.523 | 연금 수령 개시 나이 | 정상 |
| 0.532 | 연금 해지하면 어떻게 되나요 / 연금소득세 과세 어떻게 되나요 | 정상 |
| 0.597 | 세액공제 공제율 얼마인가요 | 정상 |
| 0.662 | 연금저축 세액공제 한도가 얼마인가요? / IRP 수령 요건 알려줘 | 정상 |
| 0.667 | 종합과세 기준 얼마인가요 | 정상 |
| 1.000 | 연금저축 | 정상 |

0.15 아래는 근거가 없는 질문, 0.50 위는 문서가 정면으로 답하는 질문으로 깨끗하게 갈린다.
그 사이(0.25~0.43)에는 답할 수 있는 질문과 없는 질문이 섞여 있다 — 그래서 저신뢰 구간이다.
임계값은 두 빈 구간(0.136↔0.250, 0.425↔0.523)의 안쪽에 놓았다.

**트레이드오프**

- 정상 질문에 이메일이 한 줄 붙으면 커버리지가 0.662 → 0.281로 떨어져 구간이 한 칸 내려간다.
  마스킹 때문이 아니라(원문·마스킹본 점수가 동일하다) 이메일 토큰이 질의를 희석하기 때문이다.
  `SPEC.md`가 예고한 리콜 저하가 여기서 관측된다. 답변은 계속 나가고 `⚠️`만 붙는다.
- 어휘가 어긋나면 여전히 못 찾는다. `"연금 나이 제한 있나요"`는 문서가 `연령`·`만 55세`로
  쓰고 있어 0.043(보류)이다 — 답이 문서에 있는데 놓치는 경우다. 동의어 사전은 미도입.
- `중도인출`처럼 문서의 `중도해지`·`인출분`으로 쪼개져야 맞는 복합어는 잇지 못한다.
  포함 매칭이 한 방향뿐이라 생기는 한계.
- 조사·어미 목록은 손으로 만든 것이라 빠진 접사가 있다. 형태소 분석기 도입은 여전히 범위 밖.
- 임계값은 `data/` 3개 문서 기준이다. 문서가 늘거나 검색기가 또 바뀌면 재측정 대상이라는
  ADR 0002의 조건은 그대로 유효하다.
