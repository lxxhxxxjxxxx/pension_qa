# ADR 0003 — 검색 점수는 IDF 가중 + 접두 일치 + 길이 정규화

## 상태
채택 (2026-08)

## 맥락
기존 점수는 질문 토큰과 문서 토큰의 **정확 일치 개수**였다. 세 가지 결함이 있었다.

1. **조사·복합어 리콜 구멍** — `IRP로`는 `IRP`와, `해지하면`은 `중도해지`와 겹치지 않는다.
   `"퇴직금 받았는데 IRP로 옮기면 세금 어떻게 되나요?"`는 근거 0건이 되어
   `"관련 근거 문서를 찾지 못해 답변하지 않습니다."`로 응답했다 — IRP 문서에 답이 있는데도.
2. **토큰 가중치가 전부 동일** — 3개 문서 전부에 나오는 `연금`이 한 문서에만 나오는 `세액공제`와 같은 값.
   근거 커버리지(ADR 0002)가 흔한 단어만 걸려도 올라간다.
3. **길이 편향** — 문서가 길수록 우연한 겹침이 늘어 겹침 개수만으로 유리해진다.

여기에 ADR 0001의 **입력 마스킹이 겹치면 게이트가 흐려진다**. 마스킹 결과 `h***@e***.com`이
`h`·`e`·`com`으로 쪼개져 커버리지 분모만 키우기 때문이다(실측: `"연금저축 세액공제 한도가 얼마인가요?"`
0.590 → 이메일 한 줄 덧붙이면 0.282). 정상 답변이 저신뢰로, 저신뢰가 보류로 한 칸씩 내려간다.

## 결정

```
score(문서) = Σ_토큰 idf(t) · w(t, 문서) / √|문서 토큰 수|

idf(t) = log(1 + N / max(df(t), 1))      # df=0(모르는 단어)은 df=1로 스무딩
w      = 1.0(정확 일치) | 0.5(접두 일치, 2글자 이상) | 0.0
커버리지 = Σ idf(커버된 토큰) / Σ idf(질문 토큰 전체)     # 개수 비율이 아니라 IDF 가중 비율
```

부분 일치를 **접두 방향으로만** 여는 이유: 한국어 조사·어미는 뒤에 붙으므로(`IRP로`, `한도가`)
어긋나는 쪽은 항상 꼬리다. 부분문자열까지 열면 조사 자체가 복합어에 걸린다 —
실제로 `으로`가 `연금으로`에 걸려 `"연금저축 세액공제 한도가 얼마인가요? 회신은 …으로"`의
1순위가 엉뚱하게 `IRP_수령요건`으로 뒤집혔다.

- 이메일 덩어리(`\S*@\S*`)는 **토큰화 전에 제거**한다. 원문이든 마스킹본이든 연금 용어가 아니다.
- 동점은 문서 이름순으로 고정한다(결정적 순서).
- **임계값 0.15 / 0.40은 그대로 둔다.** ADR 0002 캘리브레이션 6문항을 재측정한 결과
  전부 원래 구간에 남았다(잡담 0.125 보류 / 해지 0.181 저신뢰 / 정상 질문 0.500~0.699).
  이 표는 `tests/test_retriever.py`의 회귀 테스트로 고정했다.

## 결과
- 조사가 붙은 질문이 근거를 찾는다. 마스킹된 이메일 자체는 커버리지를 흔들지 않는다
  (`h***@e***.com`을 붙여도 `연금저축_세액공제`가 1순위, 정상 구간 유지).
- 흔한 단어만 스친 질문은 커버리지가 덜 오른다 — 게이트가 약해지지 않고 조금 더 조인다.
- **사용자에게 보이는 변화**: `"퇴직금 …IRP로 옮기면…"`이 "문서를 찾지 못했다"에서
  "근거가 부족해 보류합니다 + 관련 문서 이름(IRP_수령요건)"으로 바뀐다.
- 트레이드오프: 검색 결과 0건 경로는 범위(scope)를 통과한 질문에서 사실상 도달하지 않는다.
  경로와 문구는 유지하되, 테스트는 검색 결과를 비워서 직접 태운다.
- 트레이드오프: 접두 일치는 오탐이 있다(`연금`~`연금저축`). 그래서 반값만 인정한다.
- 트레이드오프: 복합어 안쪽 단어는 못 잡는다 — `해지`는 `중도해지`와 겹치지 않는다.
  접미 방향을 여는 값(조사 오탐으로 인한 랭킹 역전)이 얻는 값보다 컸다.
- 트레이드오프: 불용어(`어떻게`·`되나요`·`회신은`)를 **일부러 분모에 남겼다**. 제거하면 커버리지가
  전반적으로 올라 ADR 0002의 저신뢰 구간이 정상으로 밀린다 — 게이트 약화라 하지 않았다.
  대신 말이 길어질수록 구간이 한 칸 내려갈 수 있다
  (`"…한도가 얼마인가요?"` 0.590 → `"회신은 …으로"`를 덧붙이면 0.382로 저신뢰,
  `"연금 해지하면 어떻게 되나요"` 0.181 → 0.142로 보류). fail-closed 방향이라 수용한다.
- 짧은 질문에서 게이트가 무력한 구조적 약점(`"연금"` → 1.00)은 **그대로**다. IDF 가중도 단일 토큰 질문은 못 구한다.
- 여전히 형태소 분석기·임베딩이 아니다. README TODO의 임베딩 검색은 남는다.
- 문서가 늘면 임계값 재측정이 필요한 것도 그대로다. 다만 이제는 캘리브레이션 회귀 테스트가 먼저 깨져 알려준다.
