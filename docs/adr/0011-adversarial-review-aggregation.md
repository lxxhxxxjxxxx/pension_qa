# ADR 0011 — 적대적 리뷰어 다중화 + 결정적 집계

- 상태: 채택
- 날짜: 2026-09-06
- 관련: [[0010-reviewer-hardening]](0010-reviewer-hardening.md)(단일 리뷰어 견고화) · 07강 리뷰어 · 25강 output-style

## 맥락

25강까지 리뷰어는 **하나**다. 리뷰는 모델 턴이라 확률적이다 — 같은 diff도 돌릴 때마다
잡는 게 갈린다. 단일 리뷰어를 믿으면 (1) 놓침(한 번 못 보면 끝) (2) 거짓 양성(자신 있게
틀린 지적)을 그대로 게이트에 태운다. "리뷰어를 더 세게" 만드는 건 한계가 있다.

## 결정

리뷰어를 **렌즈별로 다중화**하고, 그 위에 **결정적 집계**를 얹는다.

1. **다중화(확률적)** — 같은 diff를 서로 다른 렌즈·모델의 리뷰어가 **독립**으로 본다.
   서로의 결과를 안 본다(투표가 성립하려면 독립이어야 한다). 독립은 **서브에이전트의 컨텍스트 창** 격리에서 온다 —
   `isolation: worktree`는 붙이지 않는다(2026-09-09 정정: 서브에이전트 worktree는 기본 브랜치 `main`에서 분기하고
   미커밋 변경을 포함하지 않아 세 리뷰어 모두 리뷰할 diff가 보이지 않는다. 리뷰어는 Write가 없어 격리할 것도 없다).
   - `reviewer-accuracy`(opus) — 로직·계산 오류만
   - `reviewer-security`(sonnet) — 유출·인젝션·PII·권한만
   - `reviewer-perf`(haiku) — 회귀·레이스·엣지케이스만
   - 셋이 **같은 포맷**(🔴/🟡/🟣·file:line·Summary)으로 뱉어야 기계가 묶어 셀 수 있다. 포맷은 25강 output-style과 같지만
     **각 리뷰어 본문에 직접** 들어 있다 — output-style은 서브에이전트에 적용되지 않는다(공식 문서).

2. **적대적 검증(확률적)** — 1표짜리 지적은 인센티브를 뒤집은 검증자가 **깨보려** 든다.
   깨지면(FP) 버리고, 못 깨고 **기계 증거**(grep·test)가 남으면 살린다.

3. **집계(결정적)** — 판정에 사람 주관 0. `scripts/aggregate_reviews.py`, 규칙:
   - 규칙1: 같은 file:line(±3줄)을 **≥2 리뷰어가 독립 지적** → confirm
   - 규칙2: **1표라도 적대적 검증을 기계 증거로 통과** → confirm
   - 규칙3: 적대적 검증 **논파(FP)**, 또는 **1표 + 증거 없음** → 폐기
   - 게이트: confirm된 🔴 Important > 0 → **머지 차단**(25강 게이트와 동일 선)
   - 논파는 표수를 이긴다(2표라도 FP면 폐기 — 다수결 함정 방지).

## 왜 이 경계인가

- **확률적(리뷰·검증)과 결정적(집계)을 분리**한다. 앞단은 모델이라 흔들려도, 판정은
  고정 입력→고정 출력이라 테스트로 잠긴다(`tests/test_aggregate_reviews.py`).
- **리뷰어를 3→10개로 늘려도 집계 로직은 불변**이다 — 규칙이 스케일한다.
- 사람은 confirm된 목록만 본다. 폐기 로그는 감사용으로 남기되 게이트엔 안 태운다.

## 결과

- `scripts/aggregate_reviews.py` + 고정 입력(`mock_reviews.jsonl`·`mock_verdicts.jsonl`)로
  화면에서 표·게이트가 재현된다(촬영 중 하드코딩 없이 산출).
- 회귀: `tests/test_aggregate_reviews.py` 8건(규칙1/2/3·논파 우선·결정성·Nit 비차단).
- 크로스 프로바이더(다른 벤더 모델을 리뷰어로 섞기)는 같은 포맷만 지키면 이 집계에 그대로 붙는다 —
  강의에선 강사 환경 시연(레포엔 집계·규칙·테스트만 실물). Claude Code 안에서의 다양화는 **모델 티어**(opus·sonnet·haiku·fable)다 —
  provider(API/Bedrock/Vertex/Foundry)는 세션 단위 설정이라 리뷰어별로 달리 탈 수 없고, 다른 계열 모델은 별도 도구로만 돈다.
