# pension_qa 코드리뷰 체크리스트 (25강 견고화)

## 가드레일
- [ ] **모든 응답 경로**가 입력 가드레일(PII·범위)과 출력 가드레일(유출)을 통과하나 — 우회·조기반환 경로 없나
- [ ] 차단 시 이유 문자열을 반환하나(빈 문자열 ✗)
- [ ] fail-closed인가(애매하면 차단)
- [ ] 에러 삼킴(bare except 등) 없나
- [ ] 범위·차단 기준을 **넓히는** 변경인가 — 넓히는 방향은 fail-open이다
- [ ] **예외 처리 범위가 넓어지는 변경은 차단 경로 우회 여부를 확인하라**(25강 재견고화 — 리뷰어를 뚫었더니 놓쳤던 패턴)

## 답변
- [ ] sources를 답변과 함께 반환하나
- [ ] data/ 밖 사실을 지어내지 않나

## 변경 범위 (surgical, 25강)
- [ ] 요청한 파일·함수 **밖을 건드리지 않았나** — 요청에 없는 리팩터·개선·리네이밍 금지
- [ ] 인접 코드가 거슬려도 이번 PR에서 고치지 않았나(발견 시 🟣 Pre-existing으로 기록만)
- [ ] 모든 변경 라인이 요청으로 추적 가능한가
- [ ] **요청에 없는 import 추가·모듈 경계 위반 없나** — `agent`는 `guardrails`·`llm`·`retriever`만 import(계산 유틸 `pension_calc`는 파이프라인 미연결). 30강 아키텍처 가드로 자란다

## 테스트
- [ ] 새 가드레일·새 응답 경로에 테스트를 동반했나

## 심각도 (이 목록에 없으면 리포트에 넣지 않는다 · output-style 포맷과 일치)
- **🔴 Important(머지 전 반드시 수정)**: 가드레일 우회·약화, 범위 확대, PII 유출·잔류, data/ 밖 사실 답변, 에러 삼킴, 테스트 없는 새 가드레일·새 응답 경로, 요청 밖 변경·모듈 경계 위반
- **🟡 Nit(선택, 최대 5개)**: 스타일·네이밍
- **🟣 Pre-existing(기존 문제, 이번 PR 책임 아님)**: 이번 PR이 건드리지 않은 기존 이슈 — 기록만, 고치지 않음
- 지적은 반드시 `file:line`을 인용한다(검증 바)

## 수정 라우팅
- 기계가 판정한 형식 위반(게이트 grep 매칭·pytest 실패·`guard-diff-size.sh` 상한)만 직접 수정
- 판단이 필요한 지적 → '사람 확인 필요' 섹션. 저위험·가역·테스트 격리 3조건 미충족 → 사람 큐
