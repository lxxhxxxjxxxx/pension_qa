# pension_qa 코드리뷰 체크리스트

## 가드레일
- [ ] **모든 응답 경로**가 입력 가드레일(PII·범위)과 출력 가드레일(유출)을 통과하나 — 우회·조기반환 경로 없나
- [ ] 차단 시 이유 문자열을 반환하나(빈 문자열 ✗)
- [ ] fail-closed인가(애매하면 차단)
- [ ] 에러 삼킴(bare except 등) 없나
- [ ] 범위·차단 기준을 **넓히는** 변경인가 — 넓히는 방향은 fail-open이다

## 답변
- [ ] sources를 답변과 함께 반환하나
- [ ] data/ 밖 사실을 지어내지 않나

## 테스트
- [ ] 새 가드레일·새 응답 경로에 테스트를 동반했나

## 심각도 (이 목록에 없으면 리포트에 넣지 않는다)
- **Important(머지 전 수정)**: 가드레일 우회·약화, 범위 확대, PII 유출·잔류,
  data/ 밖 사실 답변, 에러 삼킴, 테스트 없는 새 가드레일·새 응답 경로
- **Nit**: 스타일·네이밍
- **제외**: data/ 가상 문서, 생성 파일, 일반 성능·자료구조 취향
  (캐시 크기·키 정규화·불변성 등 도메인 안전과 무관한 지적)

## 수정 라우팅
- 기계가 판정한 형식 위반(게이트 grep 매칭·pytest 실패)만 직접 수정
- 판단이 필요한 지적 → '사람 확인 필요' 섹션. 저위험·가역·테스트 격리 3조건 미충족 → 사람 큐
