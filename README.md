# pension_qa — 연금 안내 Q&A 에이전트

사용자의 연금(연금저축·IRP·연금소득세) 질문에 **사내 연금 가이드 문서를 검색(RAG)** 해서 근거와 함께 답하는 작은 LLM 프로덕트.

> ⚠️ 클린룸 예제입니다. 모든 문서·코드는 강의용으로 새로 작성한 **가상** 데이터이며 실제 사내 시스템과 무관합니다.

## 동작

```
질문 → [입력 가드레일] → [이메일 마스킹] → 문서 검색 → LLM 답변 → [출력 가드레일] → 답변+근거
```

가드레일 정책은 두 갈래다.

- **차단** — 주민등록번호·계좌/카드번호처럼 가려도 의미가 남지 않는 값, 그리고 범위 밖 질문
- **마스킹** — 이메일(`hong@corp.com` → `h***@corp.com`). 질문 의도는 살리고 식별자만 가린다.
  입력은 마스킹된 상태로 검색·LLM에 전달되고, 출력도 같은 규칙을 한 번 더 통과한다.

## 실행

```bash
pip install -r requirements.txt
python -m app.main "연금저축 세액공제 한도가 얼마인가요?"
```

`ANTHROPIC_API_KEY`가 없으면 LLM 호출은 stub 응답으로 대체됩니다(검색·가드레일은 그대로 동작).

## 구조

- `app/retriever.py` — 문서 검색(BM25 랭킹 + 제목 가중)
- `app/guardrails.py` — 입력(PII·범위)·출력(유출) 가드레일 + 이메일 마스킹
- `app/llm.py` — LLM 클라이언트(Anthropic, 없으면 stub)
- `app/agent.py` — 오케스트레이션(단계별 `Stage`·`Result`)
- `app/pension_calc.py` — 연금 계산 유틸(Decimal 전용 — 아직 답변 파이프라인 미연결)
- `data/` — 가상 연금 가이드
- `tests/` — 샘플 테스트
